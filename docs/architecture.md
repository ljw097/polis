# 아키텍처

## 핵심 원칙

가장자리에만 입출력이 있고, 안쪽은 구분 없는 거대한 연결망 하나.
정해진 회로는 없어요. 신호가 흐르면서 회로가 생기고 바뀌어요.

## 2층 구조

가상 메모리와 같은 발상이에요. 프로그램이 연속된 거대 메모리를 쓴다고 믿는 동안
OS가 실제 배치를 관리하듯, 사용자와 학습 규칙은 **가상 필드**만 보고
**물리 기판**이 배치를 관리해요.

### 위층: 가상 필드 (`sim/polis/field.py`)

- 노드 아무 둘이나 연결될 수 있어요.
- 연결은 전선이 아니라 `목적지 ID → 세기` 표예요. 연결을 만들고 끊는 게 표를 고치는 일이에요.
- 동작 규칙은 [헌법](constitution.md)을 따라요.

### 아래층: 물리 기판 (`sim/polis/substrate.py`)

- **타일(시민)**: 격자로 배치된 작은 처리 단위. 가상 노드 여러 개를 들고 있어요.
- **패킷**: 노드가 발화하면 연결된 각 목적지로 패킷이 가요. 비용 = 타일 간 맨해튼 거리(홉).
- **트래픽 기록**: 타일은 노드별로 누구와 얼마나 대화했는지 기록해요. 오래된 기록은 반감기로 흐려져요.

## 이주와 연방 거버넌스

목표: 자주 대화하는 노드끼리 물리적으로 가깝게 두기.

1. **원하는 자리**: 각 노드는 대화 상대들 위치의 가중 중앙값 타일로 가고 싶어 해요 (맨해튼 비용을 최소화하는 자리).
2. **맞교환**: 타일이 가득 차 있으므로 이주는 항상 1:1 교환이에요. 두 노드의 비용 합이 줄 때만 해요.
3. **구역 자치**: 같은 구역 안의 교환은 구역이 바로 결정해요. 제한 없음.
4. **의회**: 구역을 넘는 교환은 두 구역 대표에게 제안되고, 대표들은 이득이 큰 순으로 라운드당 `treaty_budget`건만 승인해요. 구역 간 대역폭을 보호하는 장치예요.
5. **선거**: 매 라운드 각 구역에서 가장 한가한 타일이 대표가 돼요. 대표가 고장 나도 다음 라운드에 다른 타일이 이어받아요.

## 첫 실험 결과 (e01)

`experiments/e01_migration.py`. 같은 트래픽을 고정 배치와 연방 이주 기판에 동시에 흘려 비교해요.
1024 노드, 8×8 타일(타일당 16 노드), 4×4 타일 구역 4개, 입력 패턴 4개, 3000틱, 시드 0–2.

| | 고정 | 연방 이주 |
|---|---|---|
| 패킷당 평균 홉 | 5.2–5.8 | ~1.0 |
| 같은 타일 안에서 끝난 패킷 | ~1% | 34–43% |
| 구역 순도 (우연 수준 ≈ 0.29) | 0.33–0.34 | 0.60–0.81 |

구역 순도 = 각 구역에서 가장 많은 입력 패턴에 반응하는 노드의 비율.
아무도 지정하지 않았는데 구역이 특정 패턴을 맡기 시작했어요.

**한계**: 활성 노드가 약 17%뿐이에요. 내부 대부분은 조용해서, 결과는 주로 입력 근처 노드의 이야기예요.
