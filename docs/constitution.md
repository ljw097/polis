# 헌법 (Constitution)

모든 노드가 똑같이 따르는 규칙이에요. 각 조항은 **자기 자신과 직접 연결된 이웃**만
보고 판단해요. 전체 정답을 거꾸로 전파하는 신호(역전파)는 없어요.
코드: `sim/polis/field.py`의 `Constitution`.

| 조항 | 내용 | 파라미터 (v0 기본값) |
|---|---|---|
| 1조 발화 | 받은 신호가 쌓여 임계값을 넘으면 발화하고, 잠시 쉰다. 쌓인 값은 매 틱 줄어든다. | `threshold=1.0`, `leak=0.7`, `refractory=2` |
| 2조 강화 | 내 신호 직후 상대가 발화했으면 그 연결을 강하게 한다. | `lr=0.08` |
| 3조 망각 | 그렇지 않은 연결은 약해지고, 너무 약해지면 끊는다. | `decay=0.003`, `prune_below=0.02` |
| 4조 결사의 자유 | 발화한 노드는 같은 순간 발화한 아무 노드와 새 연결을 맺을 수 있다. 거리 제한 없음. | `grow_prob=0.05` |
| 5조 영향력 상한 | 한 노드의 바깥 연결 세기 합과 개수에는 상한이 있다. 독점 방지. | `budget=2.5`, `max_out=24` |

4조가 가상층의 "누구나 누구와도 연결" 원칙이고, 5조는 강화 규칙이 폭주하지 않게
막는 장치예요.
