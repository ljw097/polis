# 용어표: 기존 CS ↔ Polis

| 기존 CS | Polis | 설명 |
|---|---|---|
| ISA 분류 (RISC/CISC) | **Nomos** | 명령어 대신 헌법으로 동작하는 아키텍처 계열 |
| 명령어 세트 | **헌법 (constitution)** | 모든 노드가 따르는 국소 규칙 |
| 프로그램 | **관습 (customs)** | 학습으로 굳어진 연결 세기 |
| 프로그래밍 | **교육** | 입력을 넣고 결과에 상/벌 주기 |
| 실행 | **여론** | 신호가 퍼지며 한 방향으로 모이는 과정 |
| 메모리 주소 | **주민번호** | 가상 노드 ID |
| 가상 메모리/페이징 | **이주 (migration)** | 가상 노드의 타일 간 이사 |
| 코어/처리 단위 | **시민 (citizen) = 타일** | 노드 수백 개를 들고 있는 물리 단위 |
| NUMA 도메인 | **구역 (deme)** | 타일 묶음, 내부 이주는 자치 |
| OS 스케줄러 | **의회** | 구역 대표들의 구역 간 이주 협상 |
| 프로세스 | **기능 구역** | 사용 패턴으로 저절로 생긴 영역 |
| 버그 | **악습** | 잘못 굳어진 길 |
| 디버깅 | **재교육 / 망각** | |

참고: 물리 타일 내부는 "패킷 받기, 더하기, 임계값 넘으면 보내기" 정도의
초소형 명령어로 돌아가요. 즉 **위층은 Nomos, 아래층은 초소형 RISC**입니다.
